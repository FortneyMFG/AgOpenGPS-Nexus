# AgIO Overview

AgIO owns the transports, bridges, and hardware services that connect the
Core runtime to tractors, implements, and companion devices. Use this
folder for operator runbooks; authoritative contracts live in the
[SRS hardware layer](../development/SRS/sections/5X_Hardware_IO_Device_Layer/).
