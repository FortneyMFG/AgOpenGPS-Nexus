# Agenda

| Time (min) | Segment | Goals |
| --- | --- | --- |
| 0–10 | Welcome & objectives | Introduce Nexus rollout timeline and safety expectations. |
| 10–30 | Tooling overview | Walk through `legacy-tool` commands, Nexus import wizard, and soak harness outputs. |
| 30–55 | Migration workflow deep dive | Map each legacy asset to its Nexus destination, highlight validation checkpoints. |
| 55–65 | Break / Q&A | Address local considerations (implement types, GNSS accuracy, etc.). |
| 65–95 | Hands-on lab setup | Pair attendees with workstations, stage sample data, verify simulator access. |
| 95–140 | Guided exercises | Run translation, soak validation, and Nexus import following the checklist. |
| 140–150 | Knowledge check & wrap-up | Collect quiz responses, outline next steps for production migrations. |

Adjust time blocks based on class size. Ensure every participant completes at
least one CLI translation and one soak validation during the lab.
