# AgValonia Initiative Packet

These notes document the AgValonia modernization spike that informed Nexus UI
planning. They outline phased delivery, modernization prompts, and migration
workbooks produced while porting WinForms layouts to Avalonia.

  library and seed examples used for AI-assisted UX exploration.
- [Phase 3 workbook](ui-phase3-job-field-lifecycle.md) — field lifecycle and job
  management UX plan.
- [Phase 4 workbook](ui-phase4-settings-hotkeys.md) — settings modernization and
  hotkey strategy.
- [Migration workbook (Phase 0)](ui-migration-workbook-phase0.md) — inventory of
  legacy dialogs and their Avalonia targets.
