# AgOpenGPS v6 Mapping Internals – Technical Brief

## Overview / Architecture
Legacy AgOpenGPS v6 keeps all mapping state inside the `FormGPS` runtime: GPS samples are transformed into a local tangent plane (`LocalPlane`) at field load, implement geometry is propagated into `CSection` instances, and contiguous “on” sections stream triangle strips through `CPatches` objects that feed both on-screen OpenGL layers and periodic text-file persistence. Coverage, boundaries, AB/curve tracks, tramlines, contours, flags, and recorded paths all live in memory until autosave or job-close routines flush pending lists to disk, leaving the UI responsible for rendering and the same structures for machine control decisions.【F:Legacy SourceCode -V6/GPS/Forms/FormGPS.cs†L320-L376】【F:Legacy SourceCode -V6/GPS/Classes/CNMEA.cs†L24-L53】【F:Legacy SourceCode -V6/AgOpenGPS.Core/Models/Base/LocalPlane.cs†L5-L56】

## Visualization Pipeline

1. **Coordinate & implement update:** Each GPS fix is converted to the local plane; implement geometry is propagated through `CalculateSectionLookAhead`, which maintains per-section left/right points, speeds, and heading parity while enforcing a dynamic step distance to manage triangle density.【F:Legacy SourceCode -V6/GPS/Forms/Position.designer.cs†L1360-L1485】
2. **Section state machine:** Section timers apply look-ahead delays, set `isMappingOn`, and pack contiguous “on” bits into `triStrip` groups. Mode changes trigger `TurnMappingOn/Off`, which starts or closes triangle strips and queues lists for persistence.【F:Legacy SourceCode -V6/GPS/Forms/OpenGL.Designer.cs†L1190-L1385】【F:Legacy SourceCode -V6/GPS/Classes/CPatches.cs†L38-L160】
3. **Geometry accumulation:** `AddMappingPoint` appends alternating left/right vertices to the active triangle strip, updates worked-area totals, and splits the strip every 61 triangles to bound culling cost while storing the first `vec3` as the color swatch for multi-colored sections/zones.【F:Legacy SourceCode -V6/GPS/Classes/CPatches.cs†L48-L159】【F:Legacy SourceCode -V6/GPS/Classes/CTool.cs†L10-L112】
4. **Render passes:**
   * **Main view (`oglMain`):** Draws live patches for active sections, directional markers, boundaries, headlands, contour or AB/curve lines, tramlines, flags, and vehicle/tool geometry with layered colors and alpha blending.【F:Legacy SourceCode -V6/GPS/Forms/OpenGL.Designer.cs†L220-L449】
   * **Back buffer (`oglBack`):** Re-renders coverage strips near the vehicle for machine control previews with frustum checks to skip off-screen strips, plus tram, boundary, and headland overlays.【F:Legacy SourceCode -V6/GPS/Forms/OpenGL.Designer.cs†L760-L880】
   * **Zoom view (`oglZoom`):** Periodically repaints all stored patches using simple mip-mapping (skip vertices when zoomed out), then reads the green channel via `GL.ReadPixels` to approximate overlap intensity for statistics.【F:Legacy SourceCode -V6/GPS/Forms/OpenGL.Designer.cs†L1480-L1578】
5. **Rate/zone cues:** When multi-zone coloring is enabled, strip colors come from per-section palettes; otherwise a global coverage color (day/night alpha variants) is used. There is no continuous rate scalar—only boolean coverage plus per-zone color coding and UI textual work-rate fields.【F:Legacy SourceCode -V6/GPS/Classes/CPatches.cs†L53-L155】【F:Legacy SourceCode -V6/GPS/Classes/CFieldData.cs†L102-L158】

## Update & Persistence Strategy

* **Sampling cadence:** `gpsHz` defaults to 10 Hz; coverage points are appended on every fix when sections are active, with step distance modulated by implement twist and curve recording state.【F:Legacy SourceCode -V6/GPS/Forms/FormGPS.cs†L58-L113】【F:Legacy SourceCode -V6/GPS/Forms/Position.designer.cs†L1380-L1668】
* **Autosave rhythm:** A GUI timer increments `fileSaveCounter` roughly once per second and triggers autosave after 30 counts (≈30 s) if GPS sentences are flowing, calling `FileSaveSections/Contour/Elevation` to flush queued patches/strips.【F:Legacy SourceCode -V6/GPS/Forms/GUI.Designer.cs†L240-L272】【F:Legacy SourceCode -V6/GPS/Forms/OpenGL.Designer.cs†L1398-L1409】【F:Legacy SourceCode -V6/GPS/Forms/SaveOpen.Designer.cs†L253-L260】
* **Job close:** `FileSaveEverythingBeforeClosingField` stops mapping, turns off sections, and asynchronously writes boundaries, sections, contours, and tracks (with optional exports) before permitting field switches.【F:Legacy SourceCode -V6/GPS/Forms/Controls.Designer.cs†L598-L659】
* **Patch queueing:** `CPatches.TurnMappingOff` and triangle-count rollovers push completed strips into `patchSaveList`; these remain in memory until the next autosave or job-close flush.【F:Legacy SourceCode -V6/GPS/Classes/CPatches.cs†L78-L159】【F:Legacy SourceCode -V6/GPS/Forms/SaveOpen.Designer.cs†L253-L260】

## Known Constraints / Design Implications

* **Boolean coverage & coarse resolution:** Coverage strips encode only on/off state with alternating edge vertices. Spatial fidelity depends on implement speed and the adaptive step distance; there is no sub-strip raster or per-vertex rate payload, which limits re-use for variable-rate replay without resampling.【F:Legacy SourceCode -V6/GPS/Forms/Position.designer.cs†L1380-L1668】【F:Legacy SourceCode -V6/GPS/Classes/CPatches.cs†L100-L160】
* **File bloat & text IO:** `Sections.txt` grows linearly with every triangle pair because coverage is stored as raw text floats (including repeated color entries) without compression or tiling, leading to very large files on long jobs and slow load times.【F:Legacy SourceCode -V6/GPS/Classes/CPatches.cs†L48-L160】【F:Legacy SourceCode -V6/GPS/IO/SectionFiles.cs†L15-L60】
* **Render cost of overlap metrics:** The overlap gauge depends on full-frame `GL.ReadPixels` every zoom refresh, introducing GPU → CPU bandwidth overhead and limiting scalability for high-resolution tiles.【F:Legacy SourceCode -V6/GPS/Forms/OpenGL.Designer.cs†L1539-L1578】
* **Shared runtime state:** All map layers share mutable lists on `FormGPS`; no isolation exists between visualization, analytics, and machine control, making it hard to intercept data for Nexus without emulating the same object graph or introducing side effects.【F:Legacy SourceCode -V6/GPS/Forms/FormGPS.cs†L320-L376】【F:Legacy SourceCode -V6/GPS/Forms/OpenGL.Designer.cs†L220-L449】
* **Limited rate visualization:** Apart from per-zone colors and textual work-rate strings, there is no analog rate history; migrating to ADR-005’s layer model requires synthesizing rate layers from discrete section on/off events and external controller data.【F:Legacy SourceCode -V6/GPS/Classes/CPatches.cs†L53-L155】【F:Legacy SourceCode -V6/GPS/Classes/CFieldData.cs†L102-L158】
* **No long-term memory management:** `triStrip` retains every patch in RAM until field close, relying on manual frustum checks and coarse mip-mapping; extended sessions risk high memory pressure and degrade culling accuracy.【F:Legacy SourceCode -V6/GPS/Classes/CPatches.cs†L16-L159】【F:Legacy SourceCode -V6/GPS/Forms/OpenGL.Designer.cs†L760-L880】

### Migration Hooks

* **Import:** Reconstruct coverage by reading `Sections.txt` into Nexus layers, interpreting the first vertex color as applied zone metadata, and recomputing areas with the same triangle math for parity checks.【F:Legacy SourceCode -V6/GPS/IO/SectionFiles.cs†L15-L60】【F:Legacy SourceCode -V6/GPS/Classes/CPatches.cs†L100-L137】
* **Real-time bridge:** Monitor `triStrip` updates or section bitmasks to feed Nexus’s layer registry; contiguous bitmask grouping logic mirrors the on/off transitions required for the migration shim.【F:Legacy SourceCode -V6/GPS/Forms/OpenGL.Designer.cs†L1247-L1379】
* **AB/boundary/headland ingestion:** Use the existing text formats to seed Nexus geometry layers (AB lines from TrackLines, boundaries/headlands from Boundary/Headland files) and regenerate derived turn/headland polygons during import.【F:Legacy SourceCode -V6/GPS/IO/TrackFiles.cs†L11-L149】【F:Legacy SourceCode -V6/GPS/IO/BoundaryFiles.cs†L12-L125】

This inventory should allow a migration adapter to replay v6 coverage strips, calculate parity metrics, and stage data for ADR-005 layer tiles while highlighting the gaps (rate attributes, chunked storage, decoupled rendering) that Nexus must address.
