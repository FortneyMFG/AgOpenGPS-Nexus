# Soil & Lab Manager Plugin (Planned)

This plugin is planned for a future wave. Scope includes:

- Soil sampling workflows with zone selection, sampling routes, and submission tracking.
- Lab result ingestion (CSV, PDF parsing) with normalization to Layer Registry entries (e.g., soil organic matter, pH, nutrient levels).
- Recommendations that feed Crop Reports and Profit analytics.

No implementation decisions have been finalized; this placeholder tracks the concept in the roadmap.
