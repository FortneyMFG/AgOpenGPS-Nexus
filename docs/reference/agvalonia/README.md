# AgValonia UI Reference Packet

This packet traces the UI modernization program that bridges the legacy V6/Dev
shells and the AgValonia prototypes into the Nexus Avalonia host.

## Planning & Execution Guides

The [UI plans](ui/) outline each migration phase:

- Shell, navigation, and plugin integration goals.
- Phase-specific porting checklists for dialogs, settings, and plugin surfaces.
- Automation prompts that generate inventories, manifests, and backlogs.

## Harvested Assets

The [artifacts](artifacts/) directory stores the source material collected from
legacy repositories:

- Inventories, design specs, and theme tokens exported from the WinForms and
  AgValonia shells.
- Compliance checklists, backlog seeds, and sample screenshots that unblock
  Avalonia reimplementation work.
