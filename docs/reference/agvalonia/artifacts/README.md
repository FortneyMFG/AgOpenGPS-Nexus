# UI Migration Artifacts

These files were harvested from the V6, Dev, and AgValonia repositories to
drive the Avalonia port. They provide the authoritative inventory, licensing,
and styling data that the UI plans reference.

- [ui-inventory.json](ui-inventory.json) / [ui-inventory.csv](ui-inventory.csv)
  — Canonical list of legacy surfaces with owners, bindings, and dependencies.
- [ui-core-spec.md](ui-core-spec.md) & [ui-theme-tokens.json](ui-theme-tokens.json)
  — Component definitions and design tokens used when rebuilding controls.
- [ui-to-plugin.yaml](ui-to-plugin.yaml) — Maps UI surfaces to Nexus plugin
  manifests.
- [ui-backlog.json](ui-backlog.json) — GitHub-importable backlog entries for the
  modernization program.
- [ui-license-checklist.md](ui-license-checklist.md) — Compliance guardrails when
  reusing GPL assets.
- [ui-migration-workbook.md](ui-migration-workbook.md) — Provenance tracker with
  porting status for each surface.
- [ui-screenshots/](ui-screenshots/README.md) — Screenshot capture plan for the
  rebuilt Avalonia shell.
