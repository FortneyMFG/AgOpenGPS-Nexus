# UI Modernization Guides

Documents in this folder orchestrate the phased Avalonia port of legacy V6/Dev
and AgValonia UI surfaces. Use them to coordinate design, engineering, and
automation deliverables across the migration program.

- [UI shell and plugin integration](ui-shell-and-plugin-integration.md) — Phase 1
  plan covering shell composition, plugin wiring, and theming guardrails.
- [Phase 3: Job & field lifecycle](ui-phase3-job-field-lifecycle.md) — Dialog
  rebuild plan aligned with Nexus job/session services.
- [Phase 4: Settings & hotkeys](ui-phase4-settings-hotkeys.md) — Consolidates
  configuration flows with accessibility and persistence parity goals.
- [Phase 5: Plugin surfaces](ui-phase5-plugin-surfaces.md) — Defines the
  manifest-driven hosts for plugin-owned panels and dashboards.
- [Migration workbook (Phase 0)](ui-migration-workbook-phase0.md) — Provenance
  tracker that catalogs harvested UI assets.
- [Automation prompts](ui-modernization-ai-prompts.md) — Copy/paste scripts and
  JSON bundles for producing inventories, manifests, and compliance artifacts.
